# genropy/actions

Shared GitHub actions for Genropy projects: the build action (`action.yml`), `notify/` and `compliance/`.

- **Maintainer**: Christopher R. Gabriel (`cgabriel`), who reviews the PRs.
- **PR target**: `forgejo` for the compliance and Forgejo-registry work; ask before targeting `main` or `develop`.
- **Language**: English for issues, PRs, review comments, code comments and docs; commit messages in English.
- **Forge**: GitHub (`github.com/genropy/actions`), use `gh`. No Claude attribution in commits or PR bodies.
- **Tests**: `python3 -m unittest discover compliance/tests` (stdlib only, no external services).
